# Meet the Team Section

A beginner-friendly solution for the DevChallenges "Meet the Team" section.

## Features

- Uses CSS Grid for the desktop and tablet layouts
- Uses `position: relative` and `position: absolute` for the text overlay on each image
- Includes 5 team members with image, name, and job title
- Adapts to desktop, tablet, and mobile screen sizes
- Uses only HTML and CSS

## Project Structure

- `index.html`: the complete page and styles
- `resources/`: images, icon, and decorative assets
- `design/`: reference screenshots for desktop, tablet, and mobile

## How to Run

This is a static project, so you can open it in either of these ways:

1. Double-click `index.html`
2. Or run a local server in the project folder

```bash
python -m http.server 8000
```

Then open [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

## What This Project Practices

- Semantic HTML structure
- Responsive CSS Grid layouts
- Image overlays with gradients
- Clean spacing and typography
- Basic accessibility with alt text and clear headings

## Notes

- The code is intentionally kept simple so it is easier to teach to beginners.
- The layout follows the provided design closely without adding unnecessary styling or JavaScript.
